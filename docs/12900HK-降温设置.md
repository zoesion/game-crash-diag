# 12900HK 降温设置（ThrottleStop）

> 目标：消除 107°C 瞬时超温导致的保护关机，把游戏内 CPU 峰值压到 88°C 以内
> 适用：MSI GE76 / i9-12900HK / RTX 3080 Ti Laptop

## 为什么需要做

实测数据（2026-11-27）：

```
游戏内 CPU 封装功率: 平均 72.6W  最大 91.3W
游戏内 CPU 封装温度: 平均 88°C   最大 95°C
PL1 / PL2 静态限制:  200W / 200W      ← 等于没设上限
23:32:41  CPU 从 87°C 跳到 107°C      ← 瞬间超温
23:32:48  整机断电                     ← EC 保护关机
```

结论：不是硅脂问题（72W 才 88°C 说明接触良好），是功耗墙开太大。

## 一、下载

```
https://www.techpowerup.com/download/techpowerup-throttlestop/
```

- 解压到 `D:\Tools\ThrottleStop\`（不要放 Program Files）
- 右键 `ThrottleStop.exe` → **以管理员身份运行**

## 二、改功耗墙（先做这个，不需要关内存完整性）

1. 主界面点 **`TPL`** 按钮
2. 找到这几项：

```
PL1  (Long Power Limit)  : 200 → 55
PL2  (Short Power Limit) : 200 → 75
Time Window (秒)         : 28
```

3. 确认 **不要勾** `Disable and Lock Turbo Power Limits`
4. 点 **`Apply`** → 点 **`OK`**

### 如果数值 30 秒后又跳回 200W

说明 EC 抢回去了，再进 TPL：

- 勾上 **`Sync MMIO`**
- 再 Apply

如果还是跳回去，勾 **`MMIO Lock`**（锁死后无法再改，想改要先取消勾选并重启）。

## 三、验证是否生效

打开 HWiNFO（或我们的 v6）：

```
HWiNFO → CPU [#0] → 看这两行
  PL1 功率限制(静态): 应该变成 55.0 W
  PL2 功率限制(静态): 应该变成 75.0 W
```

然后玩一局，看：

```
CPU 封装功率 最大: 91W → 约 75~80W
CPU 封装     最大: 95°C → 约 86~88°C
过热降频时间:      90% → 接近 0%
```

## 四、持久化（重启后仍然生效）

1. ThrottleStop 主界面 → **`Options`**

```
☑ Start Minimized
☑ Unattended Start   (必要时用 "Start Minimized + Task Scheduler")
```

2. 任务计划程序（Win+R → `taskschd.msc`）→ 创建任务

```
常规:  名称 ThrottleStop
       勾 "使用最高权限运行"
触发器: 登录时（当前用户）
操作:   D:\Tools\ThrottleStop\ThrottleStop.exe
```

## 五、可选：进一步降压（效果更大，但要关内存完整性）

当前状态：**VBS 运行中 / 内存完整性 HVCI 已启用** —— 会阻止降压写入。

步骤：

1. Windows 安全中心 → 设备安全性 → 内核隔离详细信息 → **内存完整性 = 关** → 重启
2. 重启后验证：

```powershell
Get-CimInstance -Namespace root\Microsoft\Windows\DeviceGuard -ClassName Win32_DeviceGuard |
  Select-Object VirtualizationBasedSecurityStatus, SecurityServicesRunning
```

`VirtualizationBasedSecurityStatus` 应为 0 或 1（不再是 2）。

3. ThrottleStop → **`FIVR`**

```
☑ Unlock Adjustable Voltage
CPU Core  Voltage Offset: -80 mV   (先 -80，稳了再试 -100)
CPU Cache Voltage Offset: -80 mV
点 Apply
```

4. 每档验证：TS Bench 5 分钟 + 玩一局 20 分钟

不稳症状：蓝屏 0x124 / 游戏闪退 / 花屏 → 回退 20mV

预期：在 55W 功耗下，温度从 82~85°C → **74~78°C**

## 六、回滚

```
ThrottleStop → TPL → PL1/PL2 改回 200 → Apply
FIVR → Core/Cache Offset 改回 0 → Apply
或者直接退出 ThrottleStop（未设持久化时）
```

## 附：判断"要不要重涂硅脂"

| 95°C 时的封装功率 | 结论 |
|---|---|
| ≥ 65W | 硅脂没问题，只调 PL |
| 50~65W | 硅脂偏厚，可考虑 PTM7950 |
| ≤ 45W | 接触不良，必须重涂 |

当前实测 91W 峰值 / 72.6W 平均 → **硅脂没问题，不需要重涂**。
